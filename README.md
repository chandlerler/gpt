# 淘宝／天猫素材下载 · 学习版

基于上传的 3.8.7 客户端制作的独立学习副本，当前版本 **3.8.7.1**。

本地试用计时、订阅/买断校验、序号激活、设备名额限制及购买界面已移除。扫描、单品下载、失败重试和批量队列无需商业授权，不会连接原授权服务。图片处理、ZIP 打包、商品笔记等核心功能保留。

## 安装（不需要编译或安装依赖）

1. 下载 [安装 ZIP](https://github.com/chandlerler/gpt/raw/refs/heads/main/dist/taobao-tmall-study-3.8.7.1.zip)，解压到一个长期保留的文件夹。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
4. 打开淘宝或天猫商品详情页，点击扩展图标，侧栏中点击「扫描商品」。
5. 选择素材，点击下载。需要批量处理时，先在当前窗口打开多个商品详情页，再到「批量下载」加入已打开的商品。

也可以下载整个仓库或 `git clone`，然后加载仓库中的 **`extension/`**，不要选择仓库根目录。需要桌面 Chrome 114 或更新版本。

ZIP 是供解压加载使用的，不是 Chrome 商店签名的 CRX；不要直接把 ZIP 拖到扩展页安装。

## 保留的功能

- 淘宝、天猫商品主图、SKU 款式图、详情图和可读取的视频采集。
- 天猫国际可选站点权限、自动滚动、增量补抓、图片预览及筛选。
- 分类 ZIP、文件命名、商品来源 TXT、素材清单 CSV/JSON。
- 保留原档，并可生成 JPG/PNG 副本、白底方形、缩放、长图切段和容量控制。
- 当前窗口多商品标签页队列、暂停、失败项重试和中断恢复。
- 商品笔记、自有 SKU 对照、JSON/CSV 导出。
- 简体中文、繁体中文、英文及偏好保存。

运行保护仍保留：最多 30 个队列任务、100 则笔记、单次扫描 60 秒，以及图片处理的尺寸和内存保护。这些限制用于控制处理规模，不涉及订阅或付费。

## 与上传版本的区别

- 删除 `license.js`、`trial.js` 及后台授权消息处理。
- 删除单品下载、批量处理和界面中的商业使用权检查。
- 删除试用、激活、解绑、购买入口和无用的商业化文案。
- 移除 Lemon Squeezy 站点权限和支付/验证网络地址。
- 移除商店更新地址、原扩展公钥及旧商店签名元数据，作为独立副本加载。
- 名称明确标注「学习版」，帮助入口指向本仓库，保留本地诊断报告。

原扩展的本地数据不会自动迁移到这个独立副本。更新时尽量保持加载目录不变，并在扩展管理页面点击「重新加载」；更新前可先导出重要商品笔记。

## 长期使用与功能边界

这个副本没有试用到期、周期性授权或设备激活要求。原商店更新也不会自动覆盖它。后续代码更新需要自行更新该目录并重新加载扩展。

能否一直采集取决于淘宝/天猫页面结构、登录状态、素材访问条件和 Chrome API。网站改版后可能需要维护；本项目不承诺永久兼容所有商品。1688 新采集、整店遍历、通用 HLS/DASH 视频拼接并未实现。

下载期间保持商品页和侧栏打开。「已下载」表示文件已打包并交给浏览器保存，最终请检查浏览器下载列表和文件内容。

## 学习代码

| 文件 | 职责 |
|---|---|
| `extension/manifest.json` | 扩展权限与入口 |
| `platforms.js`、`page-data.js`、`content.js` | 平台识别、页面数据、DOM 采集与懒加载 |
| `sku.js`、`supplement.js` | 款式图片和增量采集 |

| `assets.js` | Canvas 图片处理 |
| `download.js`、`archive.js`、`zip.js` | 下载、命名、来源清单与 ZIP |

| `popup.html`、`popup.js`、`*-ui.js` | 侧栏交互 |

上表中未写目录的文件都位于 `extension/`。

## 验证与重新打包

扩展本身没有构建步骤，也不需要 Node/Python。以下命令仅供开发维护：

```bash
# Node.js 20+；无 npm 依赖需要安装
npm test

# 修改 _locales 后同步界面词典
npm run build:i18n

# Python 3.9+；标准库即可重新生成 ZIP 和 SHA256SUMS
npm run package
```

可选浏览器流程检查需要 Python 3.9+、Playwright 与 Chromium：

```bash
python -m pip install playwright
python -m playwright install chromium
npm run test:browser
```

测试会优先使用系统 `chromium`，也可设置 `CHROMIUM_EXECUTABLE` 指向浏览器可执行文件。所有商品与媒体均为本地构造数据，不发送真实商品请求。

已通过 11 项核心测试和 8 项浏览器流程检查，包括过期旧授权记录及 2040 年时间下的下载、真实 Canvas 转换、ZIP 读取、笔记导出、双商品队列和状态恢复。**云机器的管理员策略禁止安装未打包扩展，所以浏览器流程使用模拟 Chrome 接口；未完成真实 Chrome 扩展安装和真实淘宝登录页面验收。** 详见 [验证记录](docs/VALIDATION.md)。
