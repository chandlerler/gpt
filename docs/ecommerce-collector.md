# 电商采集大师使用说明

用于整理电商商品图片、视频、SKU、参数和评论的浏览器扩展，支持图片处理、评论分析、Excel 导出、ZIP 打包及采集历史管理。本说明适用于仓库版本 **1.2.469.2**。

本仓库整理并收录网络来源的插件代码与安装文件，原插件及相关组件的版权归各自权利人所有。

- [下载插件 ZIP](https://github.com/chandlerler/gpt/raw/refs/heads/main/dist/ecommerce-collector-1.2.469.2.zip)
- [GitHub 安装包页面](https://github.com/chandlerler/gpt/blob/main/dist/ecommerce-collector-1.2.469.2.zip)
- [原插件 Chrome 应用商店链接](https://chromewebstore.google.com/detail/nmmdfjoabpmhoaakoiclkppaokddijle)

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| 图片与视频 | 整理商品主图、SKU 图、详情图，以及页面可取得的视频 |
| 图片处理 | 调整格式、质量、缩放、文件名和保存目录，拼接详情长图 |
| SKU 与参数 | 提取规格组合、商品参数和可读取的尺码表，导出 CSV 或 Excel |
| 评论采集 | 采集评论、追评、关联图片及页面提供的规格、时间等信息 |
| 带图片的评论 Excel | 将图片直接嵌入对应评论行，下载后可离线查看 |
| 评论分析 | 查看评论统计、问题分类和风险评论，导出差评分析结果 |
| 问大家 | 在支持的淘宝／天猫商品页采集问题及回答，可按需补全回答 |
| 整合包 | 将图片、商品表格等已有采集结果合并成 ZIP |
| 采集历史 | 查看保存的记录，重新导出或打包 |
| 定时监控 | 按任务配置检查价格、库存或标题变化并提醒 |
| 界面设置 | 分别控制悬浮球显示与动画，设置主题和快捷键 |

插件包含淘宝、天猫、京东、1688／阿里巴巴、拼多多及多个亚马逊站点的适配。各平台可用功能有所不同，实际结果取决于当前页面、登录状态和网站接口。推荐使用桌面版 Chrome 或 Edge，从商品详情页开始操作。

## 安装与更新

### 首次安装

1. 下载插件 ZIP，解压到准备长期保留的文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的文件夹。
5. 打开或刷新商品详情页，点击页面悬浮球，或点击浏览器工具栏中的扩展图标。

安装不需要编译。ZIP 必须先解压；安装后不要移动或删除该文件夹。

下载链接没有响应时，打开上方的 GitHub 安装包页面，点击 **Download raw file**。私有仓库需要先登录有访问权限的 GitHub 账号。

如果下载的是整个仓库，请选择 **`plugins/ecommerce-collector/extension`** 文件夹。仓库根目录的 `extension` 属于另一个插件。

### 更新已有安装

1. 下载新版 ZIP，将其中内容覆盖到原安装目录。
2. 打开扩展管理页，点击该插件的“重新加载”。
3. 刷新已打开的商品页面。

保持原目录不变有助于保留扩展身份、本地记录和设置。重要采集结果建议提前导出备份。

## 快速上手

1. 打开商品详情页并等待加载完成，需要登录的平台先完成登录。
2. 点击悬浮球或工具栏图标打开面板。
3. 在“图片采集”“SKU采集”“评论采集”“采集历史”之间切换。
4. 检查采集结果，选择相应的下载或导出按钮。

希望一次保存多种资料时，可在采集完成后使用面板顶部的“整合包”。

## 图片、视频与长图

1. 进入“图片采集”，等待主图、SKU 图、详情图等结果出现。
2. 选择分类，勾选需要保存的素材。
3. 展开“下载设置”，调整格式、质量、缩放和文件名。
4. 点击“下载”；需要集中保存时勾选“下载为 ZIP”。

- **原始格式**：适合保存页面提供的原始素材；不发生重编码时，质量选项不会改变文件。
- **格式与缩放**：适合统一文件类型或尺寸。可用编码格式取决于浏览器支持。
- **按商品分文件夹**：方便整理多个商品的素材。
- **复制**：复制素材链接，便于记录或进一步处理。
- **详情长图下载**：将已采集的详情图拼接后保存，过长时可能分段输出。
- **以图搜货**：使用当前图片跳转到 1688 搜索相关货源。

视频是否能取得下载地址取决于平台和具体页面。

## SKU、参数与整合包

进入“SKU采集”查看规格表，再使用“SKU CSV”或“SKU Excel”导出。商品参数和尺码表以页面可读取的数据为准；缺失字段可先检查商品页面是否已展开相应区域。

“整合包”会把已有图片、SKU、参数、尺码表、上架数据表等整理到一个 ZIP，实际内容随采集结果变化。有评论数据时，相关评论文件也会进入对应打包流程。

上架数据表用于保存和整理资料；导出后仍需按目标平台或管理系统的要求检查字段并导入。

## 评论采集与导出

### 采集评论

1. 切换到“评论采集”。
2. 在“只采集前 N 条”和“采集全部评论”中选择范围。首次使用可先采集少量评论确认效果。
3. 需要淘宝／天猫问答时，勾选“同时采集『问大家』问答”；需要更多回答时，再勾选补全选项。
4. 点击“开始采集”，等待结果；需要提前结束时点击“停止采集”。

“采集全部”会尝试持续翻页或滚动，不能保证取得平台未开放的数据。若出现登录、验证或访问限制提示，先在页面处理，再继续操作。

### 选择导出格式

| 按钮 | 适用场景 |
| --- | --- |
| 导出 CSV | 保存文本和链接，便于筛选、汇总或导入其他工具 |
| 导出 Excel（含图片） | 在同一工作簿中查看评论文字及嵌入图片 |
| 导出 JSON | 保存结构化数据，方便程序处理 |
| 下载评论图片 | 单独保存可下载的评论图片文件 |
| 差评分析导出 | 整理风险评论、问题主题与分析结果 |

### Excel 图片如何显示

“导出 Excel（含图片）”会下载评论图片与追评图片，并将它们嵌入对应评论行。每张图片占一个图片列，按比例显示；原图片地址也保留在表格中。

- 图片保存在 XLSX 文件内部，下载后不需要联网加载图片。
- 为控制文件体积，嵌入的是最长边不超过 **240 像素**的缩略图；需要原图时使用“下载评论图片”。
- 图片较多时，生成工作簿需要更长时间，请等待“图片准备中”的进度完成。
- 图片失效、格式不支持或下载失败时，对应单元格会注明原因并保留原链接，其余评论仍会导出。
- CSV 和 JSON 保存文本／链接，不会像 Excel 一样直接显示嵌入图片。

请用支持 XLSX 绘图对象的表格软件打开文件；部分在线预览器可能只展示文字。评论分析结果用于辅助整理，应结合原评论判断。

## 悬浮球与动画设置

打开面板右上角“更多”菜单，可以分别设置：

| 设置 | 效果 |
| --- | --- |
| 显示悬浮球 | 控制页面侧边悬浮球是否出现 |
| 悬浮球动画 | 控制悬浮球的呼吸／扩散动画，默认关闭 |

两个开关相互独立，修改后自动保存并在刷新后恢复。

**关闭悬浮球后，仍可点击浏览器工具栏中的扩展图标打开面板。** 建议先在浏览器扩展菜单中把该图标固定到工具栏。

## 历史记录与监控

在“采集历史”中查看已保存的商品记录，选择记录后重新导出或打包。历史记录依赖当前浏览器配置中的扩展存储，卸载插件或清除数据前应先备份重要文件。

需要监控时，从“更多”菜单进入“定时监控”，按界面选择商品地址、检查字段、时间间隔和提醒方式。执行任务需要浏览器及扩展处于可运行状态；登录失效或页面变化可能导致检查失败。

## 常见问题

### 页面没有悬浮球

先通过工具栏图标打开面板，检查“显示悬浮球”开关。如果仍无法打开，确认扩展已启用、当前页面属于支持的平台，并刷新页面。

### 评论或图片比商品页面显示的少

检查是否选择了“只采集前 N 条”、页面是否已登录，以及对应评论或图片是否实际加载。平台显示的总数不一定等于当前账号能够访问的数量。

### Excel 中有的图片没有显示

先确认使用的是“导出 Excel（含图片）”，再查看图片列是否记录了失败原因。若文件已有嵌入图片但预览不显示，尝试使用支持绘图对象的桌面表格软件打开。

### 更新后界面还是旧版本

确认覆盖的是扩展当前加载的目录，点击扩展管理页中的“重新加载”，然后刷新商品页。仅重新下载 ZIP 不会更新正在运行的插件。

### 是否需要云服务

采集结果可通过本地历史记录和文件导出保存，评论分析也有本地处理流程。当前安装包未接入原作者的云存储、云端分析和团队服务。访问商品页面、下载图片及规则更新仍需要网络。
