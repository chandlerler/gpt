# 电商采集大师（本地版）

版本：1.2.469.2。基于用户提供的 1.2.469 浏览器扩展发布包修改。

[原插件 Chrome 商店页面](https://chromewebstore.google.com/detail/nmmdfjoabpmhoaakoiclkppaokddijle)

## 安装

1. 解压 `ecommerce-collector-1.2.469.2.zip` 到一个固定目录。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的目录。
5. 刷新已打开的商品页面，点击插件图标或页面悬浮按钮。

ZIP 根目录直接包含 `manifest.json`，无需 npm、编译或服务器部署。加载后不要移动或删除该目录。建议停用同类原扩展，避免同一个商品页面被重复注入面板。受组织管理的浏览器可能不允许加载本地扩展。

从上一版本更新：用新包覆盖原解压目录，在扩展管理页点击该插件的“重新加载”，然后刷新商品页。保持目录不变可以保留该扩展的本地数据与设置。

## 本次更新

- 评论页“导出 Excel（含图片）”会将图片和追评图片嵌入对应评论行，每张图片占一列，按比例缩放；图片保存在 XLSX 文件内部，离线可查看。历史/整合包中使用相同评论导出流程的表格也生效。
- 图片下载失败时，在该图片列写明原因并保留原链接；不会丢弃其他评论。导出保留图片地址列，便于获取原图。嵌入的是最长边 240 像素的缩略图，需原图时使用“下载评论图片”。图片较多时生成表格会更慢。
- 悬浮球动画默认关闭。面板右上角“更多”菜单新增“显示悬浮球”“悬浮球动画”两个独立开关，修改后自动保存。隐藏悬浮球后，仍可点击浏览器工具栏中的插件图标打开面板。

## 使用

- 图片页：选择主图、SKU 图、详情图或视频，调整格式、缩放和命名后下载；可选择 ZIP 或拼接详情长图。
- SKU 页：查看规格和参数，导出 CSV 或 Excel。
- 评论页：选择采集范围，采集评论及可取得的图片，进行本地风险分析并导出。
- 整合包：汇总图片、SKU、参数、尺码表及上架表格。
- 历史页：取回已保存的采集结果并导出。
- 更多菜单：创建定时监控任务、设置主题和快捷键。

本地采集、评论图片、ZIP、整合包、差评分析、已有批量操作及导出不需要激活码，没有授权到期时间或每日付费额度。评论图片地址可随评论一起导出；当前本地功能不依赖原授权服务器。

用户选择的评论数量/页数、采集限速、错误冷却、平台技术上限仍生效。例如问大家最多 30 页/300 问，逐问补全每次最多 80 问；部分视图仍分页或截断显示，完整已采集结果通过导出查看。平台登录、验证码和网站结构变化仍可能影响采集。

## 文件与验证

- `extension/`：可加载扩展目录。
- [安装 ZIP](../../dist/ecommerce-collector-1.2.469.2.zip)：仓库发布安装包；运行打包脚本会在本项目的 `dist/` 中生成副本。
- `tools/package.py`：打包与校验安装文件。
- `tests/core.test.cjs`：脚本/资源、离线能力、后台下载与来源检查。
- `tests/browser_smoke.py`：Chromium 页面和媒体样本测试，覆盖实际面板导出与 Canvas/ZIP。

运行验证：

```bash
node --test tests/core.test.cjs
python tests/browser_smoke.py
python tools/package.py
```

浏览器测试需要 Python Playwright、openpyxl、Pillow 与 Chromium，测试中的 Chrome 扩展 API 和电商页面使用受控样本。当前环境管理员策略禁止加载未打包扩展，因此没有将真实扩展安装、真实账号采集或所有电商网站联调标记为通过。

本次结果：8 项基础检查、10 项浏览器集成检查通过。包括工作簿内实际图片、追评图片与评论行的对应关系、重复图片复用、失效图片回退、悬浮球设置持久化、隐藏悬浮球后打开面板，以及原有导出/转码/ZIP 流程。Excel 文件由 openpyxl 离线读取验证，未进行 Microsoft Excel/WPS 界面实测。浏览器结果见 `test-results/browser-report.json`。
