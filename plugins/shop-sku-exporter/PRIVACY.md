# 隐私说明

本扩展在本地 Chrome 中运行，无遥测、分析 SDK 或采集数据上传服务。

它读取你主动发起任务的淘宝／天猫店铺和商品页；商品 ID、公开商品描述、SKU、页面提供的价格、库存、图片链接及任务状态保存在扩展的本地存储中。不会读取 Cookie API，不会导出登录令牌、请求头或账号密码。页面被动监听缓存仅驻留在页面内存，设置数量和大小上限，不写入磁盘。

任务会正常访问淘宝／天猫商品页面，这些网站仍然会按照其自身隐私政策处理浏览器请求。扩展不控制网站本身的数据处理。

导出的 Excel 保存在你选择的本地下载位置。点击「清空」删除当前本地任务；卸载扩展删除其浏览器存储，但不会删除已导出的文件。

请仅采集你有权访问的数据，并遵守网站适用的使用规则。
