# 店铺 SKU 采集 · 淘宝 / 天猫

Chrome Manifest V3 扩展。使用你已登录的浏览器，扫描店铺列表、翻页、打开商品详情，提取页面提供的 SKU 明细和价格，导出真正的 `.xlsx` 工作簿。无需编译，无第三方运行依赖。

## 安装

1. 将安装包完整解压到单独文件夹，例如 `shop-sku-exporter-v1.0.1`，不要直接在 ZIP 内操作。
2. Chrome 120 或以上打开 `chrome://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后的文件夹；打开这个文件夹时应直接看到 `manifest.json`、`background.js`、`dashboard.html`。v1.0.1 安装包的清单已放在根目录，没有额外的 `extension` 层。
5. 点击插件图标打开采集工作台。

公司管理的 Chrome 可能禁止加载未上架扩展；需要使用允许开发者模式的浏览器配置。安装后请勿移动或删除解压目录。

若出现「清单文件缺失或不可读取／无法加载清单」，请检查是否选中了上一级目录。使用旧 v1.0.0 安装包时，应选择 `shop-sku-exporter/extension`。下载整个仓库源码时，应选择 `plugins/shop-sku-exporter/extension`。

v1.0.1 修复安装包的目录层级，新增打包结构校验；采集功能保持原有实现。安装包只含运行文件和安装／隐私说明，完整源码和测试保留在仓库。

## 采集一家店铺

1. 在同一个 Chrome 配置中登录淘宝／天猫，打开目标店铺「所有宝贝」页面。
2. 工作台填写店铺列表链接。已预填本次指定店铺：`https://tongxincwyp.tmall.com/category.htm`。
3. 点击「开始采集」。插件创建独立采集标签页，先滚动列表、翻页和去重，再逐个访问商品。
4. 若页面要求登录、验证码或访问验证，任务会暂停。点击「打开采集页」，人工完成后点击「继续」。不会自动处理验证码。
5. 检查发现商品数、成功数、失败记录、价格确认状态和店铺覆盖说明。
6. 点击「导出 Excel」。采集未结束时也能导出已取得的结果。

为更稳定地加载页面，可让采集标签页保持前台。浏览器后台节流可能使采集慢于配置间隔；默认商品间隔 5 秒，最少 3 秒。请保持电脑唤醒、Chrome 打开，不要手动导航采集标签页到无关商品。

## 列表无法自动翻页时

- 进入店铺的「所有宝贝」，滚动加载商品，然后暂停任务，使用「补充当前页」读取最近访问过的淘宝／天猫页面。
- 手动翻页后重复补充。补充功能只读取当时已加载的内容，不代表自动遍历了整家店铺。
- 也可粘贴多个 `https://detail.tmall.com/item.htm?id=…` 或 `https://item.taobao.com/item.htm?id=…` 商品链接，一行一个，点击继续采集。
- 支持指定卖家 ID 以核验店铺归属；页面有店铺／卖家 ID 时会自动识别。明确属于其他店铺的商品会跳过，归属无法核验会写入备注。
- 达到页数或商品数上限、列表重复、翻页控件无法识别都会留下覆盖范围提示。发现的商品数少于页面总数时，不会标成完整覆盖。

## 价格口径

**「页面售价」和「页面明确到手价」分列，未知价格留空。**

- 通过 SKU ID 关联规格组合、价格、库存、图片；不会把商品起步价或价格区间复制给每一个 SKU。
- 只有 SKU 对应的数据明确标记「到手价」「券后价」或「优惠后价」时，才填入到手价列，同时保留优惠条件。
- 不足以识别 SKU 的页面会保留可获得的信息并提示失败或不完整，可手动重试。
- 商品没有多规格时，只在页面结构明确支持默认规格时记录默认项。
- 页面显示的价格依赖当前账号、会员资格、收货地区、活动时间、领券状态和购买数量，**并不等于已经核验的下单结算价**。
- 插件不下单、不加入购物车、不自动领券、不推算凑单或红包，不补算未知运费。对需要结算才能确认的金额，必须人工核验。
- 本版是可测试的首版适配，尚未在所提供店铺的真实登录环境验收。淘宝／天猫页面会变化，某些页面可能拿不到完整规格或明确到手价；这类项会留空或标记，不承诺任意店铺的所有 SKU 都能完整读取。

## Excel 内容

| 工作表 | 内容 |
| --- | --- |
| SKU明细 | 店铺／卖家／商品／SKU ID、标题、规格属性、页面售价、明确到手价、原价、库存、可售状态、价格来源、优惠条件、商品与图片链接、北京时间采集时间、备注 |
| 商品清单 | 发现的商品链接与采集状态、失败或跳过原因 |
| 采集说明 | 本次状态、覆盖范围、配置、价格口径及限制 |

金额为数字单元格，未知值为空；ID 为文本，避免超过 15 位后被 Excel 舍入。首行冻结并启用筛选。页面提供的标题等内容使用文本单元格，不作为 Excel 公式执行。

## 暂停、重试与数据

进度写入 `chrome.storage.local`。关闭工作台不会停止采集；手动暂停后可以继续。浏览器重启后需要点击继续。关闭采集标签页会暂停，再继续时创建标签页。失败重试保留队列，重新读取失败商品。新建任务或清空会替换当前任务，请先导出需要保留的数据。

采集数据仅保存在本地浏览器，不上传到其他服务器。扩展不读取或导出 Cookie，不要求输入账号密码，不保存原始接口响应或令牌。商品页的被动监听缓存有数量与大小限制，随页面关闭清除，只供解析使用。扩展不会主动调用私有接口或绕过访问验证。

权限：`tabs` 管理采集标签页；`scripting` 读取当前网页数据及翻页；`storage`/`unlimitedStorage` 保存队列与表格；`alarms` 在后台休眠后继续任务。网站权限仅包含淘宝和天猫 HTTPS 域名。

## 开发与验证

需要 Node.js 20+；浏览器验证另需 Python、Playwright、openpyxl 和 Chromium。

```sh
npm test
python tests/browser_smoke.py
python tools/package.py
```

核心文件：`extension/background.js` 任务调度；`extension/observer.js` 被动捕获页面已请求的详情数据；`extension/lib/extract.js` 页面适配；`extension/lib/xlsx.js` 无依赖 OOXML 导出；`extension/dashboard.*` 工作台。

单元与浏览器测试使用明确标识的模拟数据。具体测试结果见 `VALIDATION.md`，不将模拟测试视为真实店铺采集成功。
