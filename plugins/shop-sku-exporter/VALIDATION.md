## 安装后验收建议

先选 2–3 个包含多规格的商品，逐项核对 SKU 数量、规格、显示价格与优惠条件。确认适配后再扫描全店；检查页面商品总数、失败清单和到手价待确认数量。即使列表扫描结束，隐藏商品、地区不可售商品和需要额外资格的优惠仍可能无法读取。

## 复现

```sh
npm test
python tests/extract.browser.py
python tests/browser_smoke.py
python tools/package.py
```

`tests/dashboard-simulated-data.png` 等含商品行的测试截图仅展示模拟数据，不是用户指定店铺的采集结果。
