开始你的第一次采集

  1. 先登录，再打开全部商品页

    在同一个 Chrome 浏览器中登录淘宝 / 天猫，进入目标店铺的「所有宝贝 / 全部商品」页面。

  2. 读取店铺页面或粘贴链接

    点击「读取已打开的店铺页」获取页面商品，或粘贴店铺商品列表链接开始自动采集。插件会使用一个采集标签页。

  3. 查看进度，处理页面验证

    采集会自动保存。遇到登录、验证码或异常时，打开采集页手动处理，然后点击「继续采集」。请不要关闭采集标签页。

  4. 导出 Excel 工作簿

    明细包含商品、SKU、价格来源和优惠条件。可在任务完成前导出已采集数据，失败项可单独重试。

到手价取自当前登录账号可见、能明确对应到 SKU 的价格。会员、优惠券、地区及凑单条件可能影响实际付款金额。插件不会自动下单或领券。

「任务完成」表示当前发现的队列已处理，并不自动代表全店完整覆盖。请同时检查翻页覆盖说明、失败项及店铺页面的商品总数。
